# DIARRA V1 (MVP) Implementation Plan

> **Stack :** Go + Chi (backend), Next.js 15 export statique (frontend), Cloudflare Worker (edge), Cloudflare Container (Go), Neon/PostgreSQL, R2, Queues, PayDunya, Resend

**Architecture :** Trois zones (Edge Worker → Backend Go Container → PostgreSQL/R2/Queues), frontend Next.js statique servi par le Worker, API et WebSocket proxifiés vers le Container.

**Tech Stack :** Go 1.22+ / Chi / pgx / JWT / bcrypt / PayDunya API / Resend API / Cloudflare Workers / R2 / Queues / Neon PostgreSQL

---

## Phase 0 : Scaffolding & environnement dev

### Tâche 0.1 — Initialiser le module Go + serveur Chi

**Fichiers :**
- `backend/go.mod`
- `backend/cmd/server/main.go`
- `backend/internal/handler/health.go`

**Contenu :**
- Serveur HTTP Chi sur le port 8080
- Connexion PostgreSQL via pgxpool
- Endpoint GET /health → ping DB → `{"status":"ok"}`
- Graceful shutdown (SIGINT)
- Middleware : Logger, Recoverer, CORS

### Tâche 0.2 — Docker Compose local

**Fichier :** `docker-compose.yml`

**Contenu :**
- Service `postgres:16-alpine`
- Service `backend` (build ./backend/Dockerfile)
- Volume `pgdata` pour persistence
- Migration initiale exécutée au premier démarrage

### Tâche 0.3 — Migration initiale SQL

**Fichier :** `backend/migrations/001_init.sql`

**Contenu :** Schéma complet depuis la spec section 4 :
- Tables : users, user_roles, refresh_tokens, email_verifications, otp_codes, password_resets, products, referral_links, sales, delivery_links, payouts, support_tickets, ticket_messages, rate_limit_counters
- Fonctions : notify_sale_change, notify_referral_click, notify_moderation_change
- Triggers : sales_notify, referral_notify, moderation_notify

### Tâche 0.4 — Initialiser Next.js 15

**Commande :** `npx create-next-app@latest frontend --typescript --tailwind --eslint --app --src-dir --no-import-alias --use-npm`

**Configuration :**
- `output: 'export'` dans next.config.js
- API client dans `frontend/lib/api.ts`

### Tâche 0.5 — Initialiser le Worker Cloudflare

**Fichiers :**
- `worker/src/index.ts` : routing (API → container, static → ASSETS)
- `worker/wrangler.jsonc` : configuration routes, R2, Queues
